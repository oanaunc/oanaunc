# Profile maintenance

This repository powers the public GitHub profile at https://github.com/oanaunc.
GitHub displays the root README because the public repository is named `oanaunc`.

## Content sources

- Biography, technologies, education and publications: https://oanarinaldi.com/itbio.html
- Architecture background: https://oanarinaldi.com/archibio.html
- App descriptions and screenshots: https://oanarinaldi.com/apps.html and linked product pages.
- Source projects: public repositories linked in README.md.

The four product images are copied from the portfolio's existing public app assets.
The header is an original, editable SVG. It uses system fonts, includes accessible
descriptions and needs no image-generation service.

## Free services used

- GitHub profile README: https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme
- Skill Icons: https://github.com/tandpfun/skill-icons
- Shields badges: https://shields.io/badges/static-badge

No subscription, API token, paid hosting, tracking counter or scheduled job is required.
Icons and badges are loaded from their public endpoints; project screenshots and
the header are stored in this repository. Text names remain available if an icon
service is temporarily unavailable.

## Editing

Edit `README.md` to change the introduction, featured projects or links. Replace
the corresponding file in `assets/` to update a product screenshot. Edit
`assets/header.svg` to change the banner. Keep alt text accurate.

Use only public project links and public professional information. Link to product
pages for apps whose source is private. Keep repository visibility unchanged.

Recommended pins: `archi_tool`, `4d_chess`, `rubik_4D`, `draw_through`,
`pytorch_stable_diffusion`, `oanarina_website`.
